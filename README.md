# Credit Risk & Fraud Detection

## Overview

This project focuses on building Machine Learning models for:

1. Credit Risk Assessment  
2. Credit Card Fraud Detection  

### Datasets Used

• German Credit Dataset  
  - Source: UCI / Kaggle  
  - 1000 samples with 20 features  
  - Target: Good / Bad credit risk  

• Credit Card Fraud Detection Dataset  
  - Source: Kaggle (MLG-ULB)  
  - 284,807 transactions  
  - Highly imbalanced dataset (~0.17% fraud)  
  - Target: Class (0 = Legit, 1 = Fraud)  

The goal is to build robust classification models and deploy them using Streamlit.
